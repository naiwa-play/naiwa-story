# 奶蛙大进击 · 软萌远征

Three.js 制作的网页 3D 数字门跑酷游戏。独立入口，与《奶蛙来信》的存档和游戏流程分离。

## 游玩

- [公网游玩：奶蛙大进击](https://naiwa-play.github.io/naiwa-story/gates/)。无需安装，支持手机与电脑。
- 从 1 只奶蛙开始，通过数字门和三选一卡牌成长。奶蛙伙伴定时发射红色追踪奶蛋；奶狗扑咬，奶鼠搓球助攻。
- 手机按住画面横向拖动；电脑支持 A / D、左右方向键或鼠标拖动。
- 普通怪群持续推进，Boss 战停步交战。初行路结束后无缝进入无尽；怪物混合种类、随机多排站位，血量按指数曲线增长（普通怪每段 ×1.43、Boss 每段 ×1.48，按类型和强度修正），最高 999,999,999，前进速度最高 3 倍。
- 武器与攻击形式分别选择：奶蛋、投掷奶蛋、激光、火焰南瓜、机器复制枪，可搭配标准、散射、重型或急速连发。主题首领给予额外的强力奖励选择。
- 充能完成后揭晓限时模式，点击右下角按钮或按空格切换。包含愤怒、忧郁、恶魔、天使、神格；切换至少间隔 45 秒，连续击杀充能有上限。
- 碰撞扣生命，稀疏血瓶恢复生命。小怪基础掉落 1 币、Boss 5 币，可在主界面口袋商店购买开局强化和伙伴邀请。
- 柠檬海岸、蜜光密林、南瓜幽境、霓虹荒原可直接选择，各有主题首领与特有敌人。暂停、切出页面、弹窗时暂停游戏与配乐。
- 金币、商店强化和记录保存在当前浏览器；换设备或清除浏览器数据不会同步。

## 霓虹荒原与无尽成长

荒漠、铜色水塔与霓虹制造局构成赛博西部地图。两侧六组工作站循环打印奶蛙，机械臂、扫描器与传送带独立运动；复用已批准的轻量奶蛙网格和贴图，不增加大模型下载。四种机械小怪、巡逻队长及霓虹警长、铸蛙核心使用对应外形和攻击。

新地图首次选卡会出现机器复制枪。它水平发射奶蛋，命中造成伤害并分裂为两枚较小奶蛋，每代保留 65% 伤害，基础最多五代。装备时可抽到专属卡，将层数提升到 8、每次分裂数量提升到 4；本局换枪后保留升级。分裂继承剩余射程、不会重复命中沿途同一目标，所有攻击共用 155 枚同屏弹量上限。

基础成长奖励每段乘 1.14：数字门、基础攻击/伙伴卡、击杀奖励与已召唤宠物攻击同步成长。攻击力与逻辑奶蛙数量上限提高到 999,999,999；基础攻速仍最多 8，画面最多显示 64 只奶蛙，以逻辑数量折算伙伴攻击，维持手机性能。已达上限的基础卡牌退出卡池，大数使用“万 / 亿”显示。金币规则保持小怪 1 币、Boss 5 币。

## 运行与验证

纯静态文件，无服务器和运行时 npm 安装要求。使用任意静态 HTTP 服务打开本目录，或直接通过 GitHub Pages 游玩。不要使用 `file://` 打开 ES Module。

在本目录运行 `npm test`。验证武器组合、卡池权重、数值成长、碰撞与追踪、Boss 战、模式时限、商店购买和模型完整性。

`npm run models` 只重新生成奶蛋。奶蛙、奶狗、奶鼠从用户确认的 Rodin 模型导入，保留原始配色及完整身体；重新导入方法见 [CREDITS.md](CREDITS.md)。
