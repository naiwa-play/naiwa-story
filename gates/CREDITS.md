# 奶蛙大进击 · 素材与制作

这是一个非商业的同人网页游戏。角色形象相关权利归各自权利人所有。

- **当前奶蛙模型**：用户使用 Hyper3D Rodin 生成并完成上色，任务 ID `efe70d84-2b6f-4dec-b340-6cf787845531`，从用户提供的 OBJ 与 PBR 贴图导入。原始配色贴图逐字节保留，导出时转换 OBJ 与 glTF 的 V 坐标、法线贴图方向，并生成切线。`rodin-v4/naiwa-original.glb` 保留原始 500,000 三角面；游戏使用的 `rodin-v4/naiwa-jelly.glb` 为 160,000 三角面并锁定 UV 接缝，所有顶点和贴图坐标均来自原模型。模型完整保留，不切手臂、不补面、不使用关节或顶点变形。`jelly-motion.js` 对整个模型实现上下伸缩、弹跳和受击转身，保持体积。队伍使用 1,200 三角面的完整模型。Rodin 账号权益不改变第三方角色形象权利。
- **初版试验模型（当前不在游戏中使用）**：gyz6666，https://github.com/gyz6666/naiwa-static-model 。原模型按学习、练习及非商业使用范围保存；原说明为 `assets/models/NAIWA-LICENSE.md`。
- **奶狗**：使用用户确认的三视图在 Hyper3D Rodin 生成并完成贴图，任务 ID `e47ffdf8-ed0a-4538-9ba0-52b23d4b4605`。从用户提供的 OBJ 和 PBR 压缩包导入，原始 500,000 三角面另存，游戏版保留 160,000 三角面及 UV 接缝；彩色贴图逐字节保留。身体、四肢和尾巴完整保留，使用整个模型的 Q 弹伸缩，不拆分肢体。
- **奶鼠**：用户使用 Hyper3D Rodin 完成模型和贴图，任务 ID `769db8ea-c7c0-4bae-8a4e-606af7b45a80`。从用户提供的 OBJ 和 PBR 压缩包导入；原始 500,000 三角面另存，游戏版为 160,000 三角面并锁定 UV 接缝，彩色贴图逐字节保留。身体、耳朵和尾巴完整保留，沿用整个模型的 Q 弹伸缩，不拆分肢体。
- **奶蛋**：保留用户接受的简化造型，程序化模型包含 `Idle` / `Run` 动作。图片水印和用户账号没有作为游戏素材发布。
- **海岸、密林、南瓜幽境、墨团敌人、Boss、数字门、血瓶、粒子特效**：为本游戏编写的程序化三维场景。南瓜、蛛网、蜘蛛和浮动幽灵均为游戏内的三维几何，不依赖外站图片。
- **成长与保存**：奶蛙伙伴的独立追踪奶蛋、三选一卡牌、条件宠物卡池、奶蛋连射 / 五向散射 / 炸弹 / 南瓜法杖、连续无尽、金币商店均在浏览器本地运行。开局强化和金币记录通过 localStorage 保存，没有服务器或账号要求。后期采用递增的多排怪群；常规血瓶每两个无尽路段出现一次，Boss 不固定掉落血瓶。
- **配乐与音效**：背景配乐和短提示音使用本游戏编写的 Web Audio 合成音乐；“安迪”“奶蛙大笑”“嘎嘎滴辣虾”从用户提供的三段视频提取为本地 MP3，统一响度并去除第三段开头空白。卡牌使用安迪、Boss 胜利及充能就绪使用大笑、受伤使用嘎嘎滴辣虾，小怪胜利的安迪提示有 8 秒冷却。语音按优先级串行播放，播放时压低背景音乐。声音需玩家主动开启；暂停、静音及离开页面会停止语音，选卡界面允许上一段胜利语音播完。角色相关声音素材的权利归原权利人所有。
- **能量模式**：蓄满后随机揭晓愤怒、忧郁、恶魔、天使或神格的限时效果；使用基础数值计算增益，结束后自动恢复，互不叠加。就绪动画与提示音遵循声音开关和减少动态效果设置。
- **地图 Boss**：海岸的潮汐寄居蟹王、风暴水母；密林的荆棘古树、孢子巨菇；万圣节的南瓜巫师、骷髅王。使用自制几何模型和独立攻击组合，攻击统一检测主角与可见奶蛙伙伴的共享生命。
- **武器搭配**：奶蛋、投掷奶蛋、激光、南瓜法杖，与标准、散射、重型、连发形式独立组合；额外弹道可继续成长。南瓜法杖使用单独的火焰南瓜模型。普通小怪基础掉落 1 币、Boss 5 币；模式和钱袋的额外收益单独计算。倍率卡在普通卡池权重很低，主题首领另发专属成长选择。
- **无尽平衡**：普通怪基础血量按 `12 + 6n + 2n²` 随路段增长，再乘种类与波次系数；怪群增加到多排并随机错位，按进入视野的顺序生成。速度提前爬升并在 3 倍封顶。战斗充能有每秒上限，模式切换至少间隔 45 秒。
- **Three.js 0.180.0**：MIT，见 `vendor/LICENSE.txt`。运行库与 GLTFLoader、GLTFExporter 均保留 Three.js 授权。
