# 奶蛙与你 · 一起去远方

手机与电脑均可游玩的静态视觉小说，无后端、无安装依赖。GitHub Pages 从 main 根目录发布。

## 剧情与收集

全游戏 927 幕、47 个结局、12 处伏笔和彩蛋、25 件回忆物品。以下是从章节开头到结局的单次路线长度。

| 章节 | 单次幕数 | 结局 |
| --- | --- | --- |
| 序章：奶蛙来信 | 10 | 3 |
| 主线：星图失落之岛 | 94–104 | 15 |
| 海滩支线 | 90–94 | 3 |
| 热气球支线 | 89–93 | 3 |
| 雨林支线 | 89–93 | 3 |
| 惊悚故事集四篇 | 78–85，含共同入梦段落 | 20 |

路线树可直接回到已到达的选择点，阅读界面也可回到最近的选择点。跳转更新自动进度，保留手动存档。特殊结局赠送回忆物品，图鉴按已解锁结局自动收集；旧存档无需重玩。

惊悚故事集包含邮轮、林间小道、医院、歌剧院，在主线第二次路线选择后解锁。已通关主线的旧存档也可进入。入梦前位置独立保存，“醒来”恢复该位置。

## 加载与演出

启动仅等待当前立绘（初次约 85 KB），不再等待全部 31 张立绘和背景。图片下载与解码队列最长等待 2.5 秒，失败不阻止进入游戏；阅读过程中提前准备接下来八幕及邻近分支的角色图片。背景随场景加载，音乐按点击加载，角色图鉴图片按需加载。代码与剧情仍需网络下载，因此弱网情况下不能保证整页在 5 秒内打开。

立绘复用已解码的 WebP 元素，换图播放 420ms 平移渐显。结局按主题和心情使用光芒、潮汐、星轨、萤火、幕布、梦境涟漪、晨光七种演出，包含流动色彩、文字展开与小奶蛙。没有跳过动画按钮；返回地图即时可用，尊重系统减少动态效果设置。

## 开发

Node.js 18+，无需安装依赖：

```sh
npm start
npm test
```

本地地址：http://127.0.0.1:5191 。测试覆盖剧情可达性与长度、存档兼容、DLC 解锁和醒来、回溯改选、奖励迁移、下载永久挂起与解码失败。

- story.js：序章、剧情汇总、存档与推进逻辑。
- adventure.js / journeys.js：主线、普通支线及扩写。
- nightmares.js / dream-expansion.js：梦境分支、解锁与扩写。
- portraits.js：31 张立绘的情绪、构图和剧情匹配。
- relics.js：回忆物品、来源结局与说明。
- loader.js：图片缓存、限时加载。
- endings.css：主题结局动画。

角色语音待主人提供，在 media.voices 中按节点 ID 配置；配音时背景音乐降低音量。图片原稿由项目主人选择，透明 PNG 母版保留，来源见 assets/CREDITS.md。新增 14 张角色图片已处理，原有 17 张保持不变。

旧 v1 存档与结局保持兼容，单次历史最多保留 200 幕。所有进度仅保存在当前浏览器；换设备、清除浏览器数据不会保留进度。
