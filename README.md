# 奶蛙与你 · 一起去远方

手机与电脑均可游玩的静态视觉小说，无后端、无安装依赖。GitHub Pages 从 main 根目录发布。

当前章节共 1198 幕、44 个可探索结局、28 件可获得物品。旧版主线的 15 个结局与对应物品保留给旧存档，不混入新路线。以下是从章节开头到结局的单次路线长度。

| 新主线：星图失落之岛 | 145 | 6 |

路线树可直接回到已到达的选择点，阅读界面也可回到最近的选择点。跳转更新自动进度，保留手动存档。特殊结局赠送回忆物品，图鉴按已解锁结局自动收集；旧存档无需重玩。

惊悚故事集包含邮轮、林间小道、医院、歌剧院，在新主线第 80 幕抵达地下检修门后解锁。旧版已解锁进度和通关存档继续有效。入梦前位置独立保存，“醒来”恢复该位置。

## 加载与演出

启动仅等待当前立绘（初次约 85 KB），不再等待全部 31 张立绘和背景。开场最多等待图片 2.5 秒，超时后后台下载仍继续，单图超过 20 秒才取消并允许重试；阅读过程中提前准备接下来八幕及邻近分支的角色图片。背景随场景加载，音乐按点击加载，角色图鉴图片按需加载。代码与剧情仍需网络下载，因此弱网情况下不能保证整页在 5 秒内打开。

所有剧情节点都有基础立绘，显式表情按情节覆盖，没有剧情解锁限制。新表情未就绪时保留已显示的立绘或已缓存的基础立绘，下载完成后自动换图；失败时显示重试按钮，不要求刷新。立绘复用已解码的 WebP 元素，换图播放 420ms 平移渐显。结局按主题和心情使用光芒、潮汐、星轨、萤火、幕布、梦境涟漪、晨光七种演出，包含流动色彩、文字展开与小奶蛙。没有跳过动画按钮；返回地图即时可用，尊重系统减少动态效果设置。

## 开发

Node.js 18+，无需安装依赖：

```sh
npm start
npm test
```

本地地址：http://127.0.0.1:5191 。测试覆盖剧情可达性与长度、存档兼容、DLC 解锁和醒来、回溯改选、奖励迁移、下载永久挂起与解码失败。

- story.js：序章、剧情汇总、存档与推进逻辑。
- main-story.js：独立岛城主线，选择位于第 6、32、59、79、101、125、133 幕，六个新结局。
- adventure.js / journeys.js：普通支线、旧主线兼容数据及扩写。
- nightmares.js / dream-expansion.js：梦境分支、解锁与扩写。
- portraits.js：31 张立绘的情绪、构图和剧情匹配。
- relics.js：回忆物品、来源结局与说明。
- loader.js：图片缓存、限时加载。
- endings.css：主题结局动画。

角色语音待主人提供，在 media.voices 中按节点 ID 配置；配音时背景音乐降低音量。图片原稿由项目主人选择，透明 PNG 母版保留，来源见 assets/CREDITS.md。新增 14 张角色图片已处理，原有 17 张保持不变。

旧 v1 存档与结局保持兼容，单次历史最多保留 200 幕。所有进度仅保存在当前浏览器；换设备、清除浏览器数据不会保留进度。

## 远行篇

冰岛海信与白色回声从首页独立进入，没有前置解锁要求。各篇四处选择、三个结局，均有角色立绘与纪念物品。故事与配置位于 travels.js；17 张原创 SVG 场景由 make-travel-scenes.mjs 生成，涵盖市集、咖啡馆、公路、瀑布、黑沙岸、冰湖、旅舍、极光、港湾晨景，以及南大洋、科考站、冰川对照、企鹅海岸、观测室、避风湾、浮冰黄昏、极地晨景。

travels.css 增加海信、极光、暖窗、极地晨光与观测星夜五种结局主题。两种保护行动结局触发九秒全屏童话庆典：企鹅、海豹与飞鸟在晨光中出现，字幕展开后自行淡出，无需点击跳过；动画不接管鼠标/触摸，离开阅读页面会立即清理，减少动态效果下静态展示 3.5 秒。

回声站与人物为虚构。动物感谢是奶蛙画中的愿望；现实段落不喂食、触摸、追逐野生动物，清理遵从团队评估与安排，结局不会宣称一次旅行逆转全球变暖。
