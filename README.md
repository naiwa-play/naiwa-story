# 奶蛙与你 · 一起去远方

手机与电脑均可游玩的静态视觉小说，无后端、无安装依赖，GitHub Pages 从 main 根目录发布。

## 内容
- 序章《奶蛙来信》：保留三份回忆，每个结尾邀请玩家进入大冒险。
- 主线《星图失落之岛》：海岸、天空、雨林三条路线，逐层选择，12 个结局。
- 海滩、热气球、雨林三篇独立支线，各有 2 个结尾。
- 合计 125 个对话节点、21 份结局回忆，3 个可发现的小彩蛋。
- 主界面、继续旅程、路线树回溯、纪念册、手动存读档、自动续读与对白回看。

## 加载与演出
加载页预载并解码全部 17 张立绘、场景图片和音乐。图片使用 WebP，17 张合计约 1.44 MB，所有预载素材约 2.71 MB；原始透明 PNG 保留。代码和剧情随 ES 模块加载。
目标为正常网络下 5 秒内完成，但不保证弱网或 GitHub 连接的耗时；5 秒后可继续等待或进入纯文字模式，失败可重试。纯文字模式不会在后台加载完成时突然插入立绘。
立绘复用已解码的图片元素，与台词同一轮更新；换图时播放 420ms 平移渐显，同图连续台词不重复出场。结局有光芒与标题揭晓动画，可以跳过，尊重系统减少动态效果设置。

## 素材与剧情交接
- portraits.js 管理序章立绘情绪和 full / half / head / wide 构图。只采用与叙述一致的形象；主线及新增支线暂不放角色图片。
- story.js 保留序章和存档逻辑，adventure.js 是新章节、分支、结局。secrets 位于 story.js。
- 角色语音待主人提供，放入 assets 并在 media.voices 中按节点 ID 填路径；配音播放时背景音乐降低音量。
- 加入新语音时，需同时加入 loader.js 的预载清单。
- 图片原稿由项目主人选择，AI 去背景可能改变细小边缘；后续可替换为精修透明文件。来源见 assets/CREDITS.md。

旧 v1 序章存档和结局保持兼容。进度仅保存在当前浏览器；清除浏览器数据或换设备不会保留。

## DLC：惊悚故事集
新增 141 段连续对话、四篇梦中逃生故事和 20 个结局；全游戏现为 266 段对话、41 份结局回忆。噩梦里的岔路穿插于剧情：例如邮轮从交叉口分为餐厅—甲板线、楼梯—管道—救生艇线，选路后继续探索线索，再做后续选择。

解锁规则：主线第二次路线选择后进入 lighthouse / tide / station / whale / creek / gate 任一地点；已有任一主线结局的旧存档也可解锁。序章或支线结局不会提前解锁。DLC 用独立的 naiwa-before-dream-v1 记录入梦前位置，“醒来”按钮恢复该位置；手动存档保持原有规则。

nightmares.js 保存故事与解锁规则；nightmares.css 负责梦境场景。四张原创 SVG 背景位于 assets/nightmares，源码生成器为 make-night-scenes.mjs，运行 node make-night-scenes.mjs 可重建。没有强制限时、闪屏或突然音量增大的音效，慢雾动画遵循减少动态效果设置。新增故事继续不使用角色立绘，待主人提供合适素材。
